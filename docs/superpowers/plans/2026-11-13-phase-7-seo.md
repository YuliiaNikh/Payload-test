# Phase 7: SEO, Redirects, HubSpot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Yoast/RankMath parity: SEO tab (meta title/description/image with snippet preview, noindex, canonical) on pages, CPT items and terms; title pattern per language; Open Graph fallbacks; hreflang; sitemap.xml and robots.txt; JSON-LD (Organization, Article, Event, BreadcrumbList) and visible breadcrumbs; client-managed redirects plus automatic 301s when a published slug changes; HubSpot form block (inline or popup) and tracking toggle.

**Architecture:**
- Official `@payloadcms/plugin-seo` (tabbed UI, localized meta fields) with two extra fields; official `@payloadcms/plugin-redirects` (admins only).
- `autoRedirect` afterChange hook per collection: when a document that was published in the current language gets a new path, it creates `old path → document` (301) and removes any redirect from the new path (no loops).
- The page route looks up a redirect before returning 404.
- `getRouteTranslations()` returns the real URL per language (or null) for hreflang; the switcher keeps its home-page fallback.
- `sitemap.ts` reads every document once with `locale: 'all'` (slugs, breadcrumbs and per-language status in one query).
- HubSpot scripts load with `next/script` only when a form or tracking is on.
